# Website Profil SMK

## Deskripsi

Website Profil SMK merupakan website resmi sekolah yang berfungsi sebagai media informasi, promosi, publikasi kegiatan, dan penyampaian informasi kepada siswa, orang tua, calon siswa, alumni, dunia industri, dan masyarakat umum.

Website ini **bukan SIAKAD**, sehingga fokus utama adalah pengelolaan konten dan publikasi informasi.

---

# Role User

Memiliki akses penuh terhadap seluruh website.

### Hak Akses

* Mengelola halaman website
* Mengelola jurusan

* Mengelola galeri
* Mengelola guru
* Mengelola pengguna
* Mengelola menu
* Mengelola PPDB

## 2. Admin Jurusan

Setiap jurusan memiliki admin masing-masing.

### Hak Akses

* Mengelola profil jurusan
* Mengelola berita jurusan

* Mengelola prestasi jurusan
* Mengelola guru jurusan
* Mengelola kegiatan jurusan
